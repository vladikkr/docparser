# Интеграция с 1С:Предприятие 8.3

## Обзор

DocParser.ru предоставляет HTTP API для автоматического заполнения документов в 1С из фото/PDF чеков, УПД, счетов-фактур и других первичных документов.

## Варианты интеграции

### 1. Внешняя обработка (Рекомендуемый)

Создает отдельную обработку, которая:
- Позволяет выбрать файл/фото
- Отправляет в DocParser API
- Ожидает результат
- Заполняет документ в 1С

### 2. Расширение конфигурации

Встраивает функционал прямо в документы (Реализация товаров, Поступление, Акт выполненных работ).

### 3. Фоновый обмен (для массовой загрузки)

Настроить план обмена, который периодически опрашивает API и загружает документы пакетами.

## Пример кода для 1С (Внешняя обработка)

```bsl
// Модуль объекта внешней обработки

Перем HTTPКлиент, APIКлюч, БазовыйURL;

&НаКлиенте
Процедура ПриОткрытии(Отказ)
    // Инициализация
    ЗащищенноеСоединение = Новый ЗащищенноеСоединениеOpenSSL();
    HTTPКлиент = Новый HTTPКлиент(, , , , , ЗащищенноеСоединение, 30);
    
    БазовыйURL = "https://api.docparser.ru/api/v1";
    APIКлюч = Константы.DocParserAPIKey.Получить(); // Хранить в константах
КонецПроцедуры

&НаКлиенте
Функция ОтправитьДокумент(ПутьКФайлу, ТипДокумента = "receipt_kkt")
    
    // Формируем multipart/form-data
    Boundary = "----DocParserBoundary" + СтрЗаменить(Новый УникальныйИдентификатор(), "-", "");
    
    ДанныеФайла = ПолучитьДвоичныеДанныеИзФайла(ПутьКФайлу);
    ИмяФайла = Файл(ПутьКФайлу).Имя;
    
    ТелоЗапроса = Новый ЗаписьJSON;
    ТелоЗапроса.УстановитьСтроку(Новый ПараметрыЗаписиJSON(, Символы.ПС));
    
    // Используем низкоуровневое формирование multipart
    ПотокТела = Новый ПамятьПотока();
    ЗаписьДвоичных = Новый ЗаписьДвоичныхДанных(ПотокТела);
    
    // Часть: file
    ЗаписьДвоичных.Записать(КодСимвола("--") + Boundary + Символы.ПС);
    ЗаписьДвоичных.Записать("Content-Disposition: form-data; name=\"file\"; filename=\"" + ИмяФайла + "\"" + Символы.ПС);
    ЗаписьДвоичных.Записать("Content-Type: application/octet-stream" + Символы.ПС + Символы.ПС);
    ЗаписьДвоичных.Записать(ДанныеФайла);
    ЗаписьДвоичных.Записать(Символы.ПС);
    
    // Часть: document_type
    ЗаписьДвоичных.Записать(КодСимвола("--") + Boundary + Символы.ПС);
    ЗаписьДвоичных.Записать("Content-Disposition: form-data; name=\"document_type\"" + Символы.ПС + Символы.ПС);
    ЗаписьДвоичных.Записать(ТипДокумента + Символы.ПС);
    
    // Конец
    ЗаписьДвоичных.Записать(КодСимвола("--") + Boundary + "--" + Символы.ПС);
    ЗаписьДвоичных.Закрыть();
    
    ТелоДвоичные = ПотокТела.ЗакрытьИПолучитьДвоичныеДанные();
    
    // Отправляем запрос
    Запрос = Новый HTTPЗапрос(БазовыйURL + "/documents/parse");
    Запрос.Заголовки.Вставить("X-API-Key", APIКлюч);
    Запрос.Заголовки.Вставить("Content-Type", "multipart/form-data; boundary=" + Boundary);
    Запрос.УстановитьТелоИзДвоичныхДанных(ТелоДвоичные);
    
    Ответ = HTTPКлиент.Выполнить(Запрос);
    
    Если Ответ.КодСостояния <> 200 Тогда
        ВызватьИсключение "Ошибка отправки: " + Ответ.КодСостояния + " " + Ответ.ПолучитьТелоКакСтроку();
    КонецЕсли;
    
    Результат = ПрочитатьJSON(Ответ.ПолучитьТелоКакСтроку());
    Возврат Результат.document_id;
КонецФункции

&НаКлиенте
Функция ПолучитьРезультат(DocumentID)
    Запрос = Новый HTTPЗапрос(БазовыйURL + "/documents/" + DocumentID);
    Запрос.Заголовки.Вставить("X-API-Key", APIКлюч);
    
    Попытки = 0;
    Пока Попытки < 30 Цикл
        Ответ = HTTPКлиент.Выполнить(Запрос);
        
        Если Ответ.КодСостояния = 200 Тогда
            Результат = ПрочитатьJSON(Ответ.ПолучитьТелоКакСтроку());
            
            Если Результат.status = "completed" Тогда
                Возврат Результат.parsed_data;
            ИначеЕсли Результат.status = "failed" Тогда
                ВызватьИсключение "Ошибка парсинга: " + Результат.error_message;
            КонецЕсли;
        Иначе
            ВызватьИсключение "Ошибка получения результата: " + Ответ.КодСостояния;
        КонецЕсли;
        
        Попытки = Попытки + 1;
        // Ждем 2 секунды
        Задержка(2000);
    КонецЦикла;
    
    ВызватьИсключение "Превышено время ожидания парсинга";
КонецФункции

&НаКлиенте
Процедура ЗаполнитьЧекККТ(ПутьКФайлу)
    DocumentID = ОтправитьДокумент(ПутьКФайлу, "receipt_kkt");
    Данные = ПолучитьРезультат(DocumentID);
    
    // Создаем документ "Поступление товаров и услуг" или "Реализация"
    Документ = Документы.ПоступлениеТоваровУслуг.СоздатьДокумент();
    Документ.Дата = Данные.date_time;
    Документ.Контрагент = НайтиИлиСоздатьКонтрагента(Данные.seller);
    Документ.ДоговорКонтрагента = НайтиДоговор(Документ.Контрагент);
    Документ.Организация = НайтиНашуОрганизацию(Данные.seller.inn);
    Документ.Склад = НайтиОсновнойСклад();
    
    Для Каждого Строка Из Данные.items Цикл
        Номенклатура = НайтиИлиСоздатьНоменклатуру(Строка.name);
        Документ.Товары.Добавить().Заполнить(Номенклатура, Строка.quantity, Строка.price, Строка.vat_rate);
    КонецЦикла;
    
    Документ.Записать(Истина);
    Сообщить("Документ создан: " + Документ.Номер);
КонецПроцедуры

&НаКлиенте
Функция НайтиИлиСоздатьКонтрагента(Продавец)
    // Поиск по ИНН/КПП
    Запрос = Новый Запрос;
    Запрос.Текст = "
    |ВЫБРАТЬ ПЕРВЫЕ 1
    |    Контрагенты.Ссылка
    |ИЗ
    |    Справочник.Контрагенты КАК Контрагенты
    |ГДЕ
    |    Контрагенты.ИНН = &ИНН
    |    И Контрагенты.КПП = &КПП";
    Запрос.УстановитьПараметр("ИНН", Продавец.inn);
    Запрос.УстановитьПараметр("КПП", Продавец.kpp);
    Результат = Запрос.Выполнить().Выбрать();
    
    Если Результат.Следующий() Тогда
        Возврат Результат.Ссылка;
    КонецЕсли;
    
    // Создаем нового
    НовыйКонтрагент = Справочники.Контрагенты.СоздатьЭлемент();
    НовыйКонтрагент.Наименование = Продавец.name;
    НовыйКонтрагент.ИНН = Продавец.inn;
    НовыйКонтрагент.КПП = Продавец.kpp;
    НовыйКонтрагент.ЮридическийАдрес = Продавец.address;
    НовыйКонтрагент.Записать();
    
    Возврат НовыйКонтрагент.Ссылка;
КонецФункции
```

## Настройка вебхуков (для фонового режима)

1. В 1С создать HTTP-сервис (например, `/docparser/webhook`)
2. В DocParser при загрузке указать `webhook_url`
3. При завершении парсинга DocParser отправит POST с результатом

```bsl
// HTTP-сервис в 1С
Процедура ОбработатьWebhook(Запрос, Ответ) Экспорт
    Данные = ПрочитатьJSON(Запрос.ПолучитьТелоКакСтроку());
    
    Если Данные.event = "document.parsed" И Данные.document.status = "completed" Тогда
        // Запускаем фоновое задание на заполнение
        ФоновыеЗадания.Выполнить("ЗаполнитьИзDocParser", Данные.document);
    КонецЕсли;
    
    Ответ.КодСостояния = 200;
КонецПроцедуры
```

## Хранение API ключа

Рекомендуется хранить в:
- Константах конфигурации (защищенные)
- Параметрах сеанса
- Отдельном справочнике "Настройки интеграций"

## Тестирование

Используйте тестовый режим:
- `ENVIRONMENT=development` в DocParser
- Бесплатный тариф (50 док/мес)
- Тестовые файлы из `tests/fixtures/`

## Поддержка

При проблемах интеграции:
1. Проверьте логи DocParser (Sentry/Render logs)
2. Убедитесь в корректности API ключа
3. Проверьте формат файлов (поддерживаемые MIME types)
4. Обратитесь в поддержку: support@docparser.ru
