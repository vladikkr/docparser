# Осталось сделать вам: два шага

Всё остальное уже сделано и проверено. Эти два шага нельзя выполнить кодом:
первый — сообщение в Telegram, второй — вход в аккаунт под вашим именем.

---

## Шаг 1. Перевыпустить токен бота (2 минуты)

**Зачем.** Токен попал в историю этого чата. Любой, кто его прочитает, сможет
читать сообщения клиентов и писать от имени бота. Это единственная открытая
дыра в безопасности.

1. Откройте **@BotFather**
2. Напишите `/revoke`
3. Выберите из списка `docparser_by_bot`
4. BotFather выдаст **новый** токен
5. Впишите его себе в терминал:

```powershell
cd C:\Users\vladk\OneDrive\Desktop\Work\Work\user\docparser-ru
python scripts\set_bot_token.py
```

Токен вводится скрытым вводом: на экране ничего не появится, в историю команд
он не попадёт. Старый токен после `/revoke` перестаёт работать.

**Если пропустить.** Формально бот продолжит работать. Риск в том, что токен
из переписки утечёт.

---

## Шаг 2. Задеплоить бота на Render (5 минут)

**Зачем.** Сейчас бот работает на вашем компьютере. Когда компьютер выключен
или перезагружается, клиенты не могут ничего прислать. Это единственное
существенное ограничение продукта.

1. Зарегистрируйтесь на [dash.render.com](https://dash.render.com)
2. Откройте **Account Settings → API Keys → Create**
3. Скопируйте ключ (начинается с `rnd_`)
4. Запустите:

```powershell
python scripts\deploy_render.py
```

Скрипт спросит ключ скрытым вводом и **сам** выполнит остальное: создаст
воркер, поставит переменные, запустит сборку, дождётся её и напишет результат.

Первая сборка занимает 5–10 минут — ставится Tesseract.

**После успешного деплоя** остановите локальную копию, иначе два процесса
с одним токеном и оба перестанут отвечать:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\bot_service.ps1 stop
```

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `Ключ не принят` | Ключ вставлен не полностью или от другого аккаунта |
| `Создание не удалось` | Покажите текст ответа, там будет причина |
| `Сборка не завершилась` | Логи: [dash.render.com](https://dash.render.com) → сервис → Logs |
| `bot_started` нет в логах | Пришлите лог, разберёмся |
| Бот молчит после деплоя | Проверьте, что локальная копия остановлена |

Полная инструкция с картинками и объяснениями: `docs\deploy_bot_render.md`
